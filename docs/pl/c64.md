# Port Commodore 64

- PRG: `$0801`, stub BASIC `10 SYS2061`, kernel od `$0810`, DB=`$2400`, sloty programów `$4000/$7000/$A000` (po 12 KB).
- BIOS kopiowany do RAM (`$F800` tablica skoków, reszta `$E800`); ROM-y wyłączone (`$01=$35`), KERNAL nieużywany.
- Konsola: VIC-II tekst 40x25 pod `$0400`, zestaw znaków 2, kursor = blok reverse.
- Klawiatura: skan macierzy CIA1 z debounce. Timer: CIA1 A, 9852 cykli (PAL ~100 Hz; NTSC ~103,8 Hz).
- RTC: CIA1 TOD (start 09:00, data stała 2026-10-11). Dysk: REU (DMA `$DF00`), blok = bank/offset.
- Test: VICE x64sc headless (18 kontroli) z zastępczymi ROM-ami oraz z oryginalnymi (KERNAL 901227-03, BASIC, chargen; `C64_ROMS=katalog`, autostart PRG przez KERNAL).
- Do potwierdzenia: test na prawdziwych ROM-ach i sprzęcie; backend IEC/SD; PET.

## Cartridge (Magic Desk)

- Typ CRT 19, 16 banków x 8 KB (`tools/mkcart.py`, `cartconv -t md`). Bank 0: nagłówek CBM80, boot, obraz BIOS. Banki 1-15: dysk 480 bloków (32 bloki/bank), tylko do odczytu.
- Start: KERNAL sprawdza CBM80 jako pierwszy krok resetu (przed IOINIT), więc boot sam ustawia port: najpierw zatrzask `$01=$37`, dopiero potem DDR `$00=$2F` (odwrotna kolejność zerowała zatrzask i odcinała cartridge). Boot kopiuje BIOS do `$E800`/`$F800` (zapis idzie do RAM pod ROM), kopiuje 7-bajtowy trampolinę do `$0334` i skacze do niej; trampolina ustawia `$01=$35` (cartridge znika) i skacze do `Reset`.
- ROML widać tylko przy LORAM=HIRAM=1 (`$01=$37`), więc czytnik banków (`RomRd`, ~70 B) jest kopiowany do RAM pod `$0340`. Czytnik: SEI, `$01=$37`, wybór banku zapisem do `$DE00`, kopia 256 B, przywrócenie `$01`, X/Y i I. Samomodyfikacja dotyczy kopii w RAM.
- Blok b -> bank 1 + b/32, adres `$8000 + (b mod 32)*256`; b >= 480 zwraca błąd.
- Z REU: POST kopiuje 480 bloków ROM do REU i dalej używa REU (dysk zapisywalny, wiersz `DISK ... OK 512 KB +ROM`). Bez REU: `blk_mode=1`, odczyt z banków, zapis zwraca błąd 3 ("I/O error"), wiersz `OK RO 120 KB ROM`.
- Ograniczenia: dane z zapisów bez REU nie są przechowywane; NMI (RESTORE) podczas odczytu bloku nie jest obsługiwany (odczyt trwa ~3 ms przy SEI); test tylko w VICE z oryginalnymi ROM-ami.
