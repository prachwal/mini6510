# Documentation

Two language folders; the images (`img/`) and the disassemblies (`disasm/`) are shared.

- [`en/`](en/): English. The translations of all original notes (`overview`, `architecture`, `cpu`, `memory`, `platform`, `bios-api`, `testing-plan`, `verification-notes`, `c64`, `plus4`, `decisions`) and the newer documents written in English (`drives`, `drivers`, `xip`, `graphics`, `musicplay`, `roadmap-0.2`).
- [`pl/`](pl/): Polski. Oryginalne notatki projektowe (te same 11 plików co wyżej). Nowsze dokumenty (`drives`, `drivers`, `xip`, `graphics`, `musicplay`, `roadmap-0.2`) są na razie tylko po angielsku; `pl/decisions.md` zawiera ich skrót po polsku.

When a document changes, update both languages (the English file is the reference for the newer documents).
