# Commodore 64 port

- PRG: `$0801`, BASIC stub `10 SYS2061`, kernel from `$0810`, DB=`$2400`, program slots `$4000/$7000/$A000` (12 KB each).
- The BIOS is copied to RAM (`$F800` jump table, the rest at `$E800`); ROMs off (`$01=$35`), KERNAL not used.
- Console: VIC-II text 40x25 at `$0400`, character set 2, cursor = reverse block.
- Keyboard: CIA1 matrix scan with debounce. Timer: CIA1 A, 9852 cycles (PAL ~100 Hz; NTSC ~103.8 Hz).
- RTC: CIA1 TOD (starts at 09:00, fixed date 2026-10-11). Disk: REU (DMA `$DF00`), block = bank/offset.
- Test: VICE x64sc headless (18 checks) with replacement ROMs and with the original ones (KERNAL 901227-03, BASIC, chargen; `C64_ROMS=directory`, PRG autostart through the KERNAL).
- To confirm: test on real ROMs and hardware; IEC/SD backend; PET.

## Cartridge (Magic Desk)

- CRT type 19, 16 banks x 8 KB (`tools/mkcart.py`, `cartconv -t md`). Bank 0: CBM80 header, boot, BIOS image. Banks 1-15: a 480-block disk (32 blocks per bank), read-only.
- Start: the KERNAL checks CBM80 as the first step of reset (before IOINIT), so the boot code sets up the port itself: first the latch `$01=$37`, only then DDR `$00=$2F` (the reverse order cleared the latch and cut off the cartridge). The boot code copies the BIOS to `$E800`/`$F800` (the write goes to RAM under the ROM), copies a 7-byte trampoline to `$0334` and jumps to it; the trampoline sets `$01=$35` (the cartridge disappears) and jumps to `Reset`.
- ROML is visible only with LORAM=HIRAM=1 (`$01=$37`), so the bank reader (`RomRd`, ~70 B) is copied to RAM at `$0340`. The reader: SEI, `$01=$37`, bank select by a write to `$DE00`, copy 256 B, restore `$01`, X/Y and I. Self-modification affects the copy in RAM.
- Block b -> bank 1 + b/32, address `$8000 + (b mod 32)*256`; b >= 480 returns an error.
- With a REU: POST copies the 480 ROM blocks to the REU and keeps using the REU (writable disk, row `DISK ... OK 512 KB +ROM`). Without a REU: `blk_mode=1`, reads from the banks, a write returns error 3 ("I/O error"), row `OK RO 120 KB ROM`.
- Limitations: data from writes is not kept without a REU; NMI (RESTORE) during a block read is not handled (the read takes ~3 ms with SEI); tested only in VICE with the original ROMs.
