# Port Commodore 64

- PRG: `$0801`, stub BASIC `10 SYS2061`, kernel od `$0810`, DB=`$2400`, sloty programów `$4000/$7000/$A000` (po 12 KB).
- BIOS kopiowany do RAM (`$F800` tablica skoków, reszta `$E800`); ROM-y wyłączone (`$01=$35`), KERNAL nieużywany.
- Konsola: VIC-II tekst 40x25 pod `$0400`, zestaw znaków 2, kursor = blok reverse.
- Klawiatura: skan macierzy CIA1 z debounce. Timer: CIA1 A, 9852 cykli (PAL ~100 Hz; NTSC ~103,8 Hz).
- RTC: CIA1 TOD (start 09:00, data stała 2026-10-11). Dysk: REU (DMA `$DF00`), blok = bank/offset.
- Test: VICE x64sc headless (18 kontroli) z zastępczymi ROM-ami KERNAL/chargen.
- Do potwierdzenia: test na prawdziwych ROM-ach i sprzęcie; backend IEC/SD; PET.
